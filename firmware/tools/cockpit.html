Data source

The display is a 256 × 64 one-bit dot matrix (estimated from the photo: 4:1 glass, a 5 × 7 small font and the same font at 2× for the main line), drawn with a hand-made 5 × 7 bitmap font with descenders and Polish letters; every dot is either ink or backlight. Change LCD_W / LCD_H in the script if the real panel differs. Demo mode runs a simulated phone. With a Pico on USB the page reads the @J JSON lines from the firmware console and sends the console keys (n, b, space). Web Serial needs Chrome or Edge and is blocked inside claude.ai: open firmware/tools/cockpit.html from the repo directly in the browser.
